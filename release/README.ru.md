# TF1 Runoff 0.3.4

Версия 0.3.4 включает подтверждённые настройки коллизий 20 типов моделей (ревизия 7). Для Runoff по умолчанию применяется `mat_sky_scale 0.4`; при выходе прежнее значение восстанавливается.

Полная сборка: **один мод `TF1.Runoff`, один ZIP**, одинаковый пакет для клиента и сервера. Старые архивы 0.3.0 / 0.3.2 не нужны.

Включены карта, модели, текстуры со всеми mip-уровнями, новый `.stbsp`, соединения двух проходов для титанов, исправления коллизий, освещения, теней, воды, эффекты, звук труб и изображения в меню и при загрузке. Диагностические моды не включены. Обычные карты доступны. Frontier Defense не включён.

## Установка

Нужны установленные Titanfall 2 и Northstar с модами версии **1.31.13**. Python устанавливать не нужно.

1. Распакуй ZIP полностью и закрой игру и сервер.
2. Запусти `Install-Runoff.cmd` и выбери папку с `NorthstarLauncher.exe`.
3. Установщик подготовит профили `RunoffClient` и `RunoffServer`, используя установленный `R2Northstar` как основу.
4. Для игры запускай `RunoffClient/Start-RunoffClient.cmd`. Звуковой компонент труб запускается автоматически.
5. Для локального выделенного сервера запускай `RunoffServer/Start-RunoffServer.cmd`.

Если базовый профиль называется иначе:

```powershell
.\Install-Runoff.exe --game "D:\Games\Titanfall2" --base-profile ИмяБазовогоПрофиля --profiles RunoffClient RunoffServer
```

Старые отдельные моды Runoff сохраняются и отключаются. Заменяемый объединённый мод и настройки включения сохраняются в `runoff-backups` внутри профиля. Не включай старые компоненты одновременно с новым `TF1.Runoff`.

Для звука труб используй комплектный запуск клиента. Обычный запуск `NorthstarLauncher.exe` самостоятельно не запускает звуковой компонент.

Сжатие моделей и старых материалов — LZHAM без потерь. Текстуры не уменьшены, файлы карты не вырезаны. `.stbsp` использует консервативные оценки без расчёта перекрытия поверхностей стенами.

Редкие ранее замеченные краши `datacache.dll` при переходах между матчем и лобби пока нельзя считать полностью устранёнными. Запуск публичного интернет-сервера отдельно не проверен; комплектный серверный запуск настроен для локальной игры.

Исправлено декодирование нормалей 40 материалов и исходный масштаб детализации у всех 23 материалов с detail normal. Проверены 1856 записей исходных текстур и mip-уровни; разрешение сохранено. Полное визуальное совпадение с TF1 для блеска, Fresnel и дополнительных detail normal у смешанных материалов пока не подтверждено.

Комплектный запуск сохраняет резервную копию серверного autoexec в `runoff-original-autoexec_ns_server.cfg` внутри профиля и применяет локальные настройки. Для публичного сервера восстанови эту копию в `mods/Northstar.CustomServers/mod/cfg/autoexec_ns_server.cfg` и используй собственные настройки запуска.
